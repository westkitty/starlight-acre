# Starlight Acre — Visual Canon

Art-direction consolidation pass over the complete 136-candidate foundry library
(original 44 + ALT 44 + additional 24 + additional-ALT 24). This directory is the
project's durable visual truth for future generation.

## Ratification gate (REQUIRED before any art repair)

**Metric-derived selection ≠ human-ratified canon.** The selections in
`VISUAL_CANON_SELECTIONS.json` are measurement-grounded DRAFTS. Human visual
ratification must happen BEFORE any repair or regeneration is spent:

1. open `ratify.html` (offline console; high-risk slots first)
2. visually review all 29 slots — P/S/O/N/D decisions, notes, game-scale board
3. click **EXPORT RATIFICATION** → `RATIFICATION_DECISIONS.json`
   (or **COPY JSON** and paste it back into the Arena chat)
4. place the file in this directory (or hand it to the agent)
5. run `python3 apply_ratification.py`
6. inspect `RATIFIED_VISUAL_CANON.json` (refuses to complete while any slot is
   DEFER or missing; NEEDS_NEW_REFERENCE slots are recorded as gaps)
7. inspect `RATIFIED_REPAIR_QUEUE.json` — the SMALLEST justified repair set
   (only defects on the ratified canon itself; everything else is
   `PRESERVE_AS_REJECTED_CANDIDATE` with original files untouched)
8. only then execute repairs
9. only after repair validation promote assets to the live game

Decisions persist in localStorage (`starlight-acre-visual-ratification-v1`) and
can be re-imported. The compiler never invents decisions and never repairs art.

## Files

- `ratify.html` — HUMAN RATIFICATION CONSOLE (decision gate; generated by
  `tools_canon_build_ratify.py`)
- `apply_ratification.py` — ratification compiler → `RATIFIED_VISUAL_CANON.json`
  + `RATIFIED_REPAIR_QUEUE.json` (refuses incomplete/DEFER/cross-slot input)
- `STARLIGHT_ACRE_VISUAL_CANON.md` — the canon: visual thesis, pixel density,
  outline, lighting, palette, material, machinery/drone/terminal/biology/environment/
  UI/VFX grammar, Dexter lock, forbidden drift
- `MASTER_ASSET_INDEX.json` — all 136 candidates with pixel metrics + observations
- `VISUAL_CANON_SELECTIONS.json` — per-slot PRIMARY / SECONDARY /
  REJECT_AS_STYLE_REFERENCE drafts with reasons
- `reference_atlas.html` — offline atlas of selected references + GAME SCALE board
- `VISUAL_CONTINUITY_REPORT.md` — cross-family drift audit
- `COHESION_REPAIR_QUEUE.json` — 25 unpruned draft entries (9 NORMALIZE_ONLY,
  6 TARGETED_IMAGE_EDIT, 10 REGENERATE); pruning happens only after ratification
- `FUTURE_ASSET_GENERATION_CONTRACT.md` — binding pre-generation reads + minimum
  reference sets per family
- `tools_canon_analyze.py` — reproducible analyzer (builds index/selections/summary)
- `tools_canon_build_atlas.py` — builds `reference_atlas.html`
- `tools_canon_build_ratify.py` — builds `ratify.html`
- `canon_metrics_summary.json`, `continuity_outliers.json` — intermediate data

## Method (honesty note)

The analysis environment has no image-viewing capability. All observations are
deterministic pixel measurements (palette-anchor usage, outline-ring darkness,
edge density, cluster run length, lighting bias, glow ratio, coverage) computed
from each candidate's `game_ready.png`, combined with recorded prompts, technical
flags and run-verification history. Selections are measurement-grounded
art-direction drafts for human ratification via the review tools. No candidate
file was modified in this pass.

## Reproduce

```
python3 tools_canon_analyze.py      # rebuild index/selections/summary/outliers
python3 tools_canon_build_atlas.py  # rebuild reference_atlas.html
```
